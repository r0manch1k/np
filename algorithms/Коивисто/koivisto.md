## 1. Введение

Покажем, что для данного набора $m$ ограничений над $n$ переменными, присваивание значений переменным, которое удовлетворяет максимальное количество ограничений ($MAX\text{-}2\text{-}CSP$) может быть найдено за время $O^*(n m d^{n \omega / 3})$, где $d$ - максимальное число возможных значений для каждой переменной и $w < 2.372$ - экспонента произведения матриц над кольцом. Нотация $O^*$ поглощает факторы, полилогарифмические от $m$ и $n$. Как следствие, задача $MAX\text{-}2\text{-}SAT$ и $MAX\text{-}CUT$ может быть решена за время $O^*(n m 1.729^n)$. Это улучшает предыдущий результат [Райна Виллиамса](./../Виллиамс/williams.md), сокращая полиномиальный фактор с $nm^3$ до $nm$.

## 2. Задача выполнения ограничений

Рассмотрим следующий вариант задачи определения максимального количества выполняющихся ограничений. Вход состоит из $n$ переменных $x_1, \ldots, x_n$, где каждая $x_i$ берёт свои значения из конечного множества $\chi_i$ размера $d_i$, и $m$ (взвешенных) ограничений $w_1, \ldots, w_m$, каждое из которых является целочисленной функцией над подмножеством переменных. Задача состоит в нахождении присваивания значений для переменных, при котором сумма весов выполненных ограничений будет максимальной.

Для удобства введём следующие обозначения.

_Областью определения_ $c$-ого ограничения $w_c$ назовём подмножество индексов $S_c \subseteq \\{1, \ldots, n\\}$, от которого будет зависеть вектор переменных $x_{s_c}$ со значениями из $\chi_{S_c}$ (_я так понимаю он это ввёл, чтобы устранить некоторую неопределённость c $a_v$ у Виллиамса_). Здесь и далее используется индексирование через подмножества: если $S = \\{i_1, \ldots, i_k\\}$ с $1 \leq i_1 < \ldots < i_k \leq n$, то $\chi_S$ является $\chi_{i_1} \times \cdots \times \chi_{i_k}$, а $x_S$ будет $(x_{i_1}, \ldots, x_{i_k})$; для $S = \\{1, \ldots, n\\}$ индексы можем опустить.

Таким образом, ограничение $w_c$ отображает каждое частичное присваивание $x_{S_c}$ из $\chi_{S_c}$ в целое положительное число из $\\{0, 1, 2, \ldots\\}$ (не рассматриваем отрицательные веса). Будем говорить, что присваивание $x \in \chi$ удовлетворяет ограничению $w_c$, если значение $w_c(x_{S_c})$ больше нуля. _Суммарный вес_ ограничейний $w_1, \ldots, w_m$ при $x$ является суммой всех их весов - $w_1{x_{S_1}} + \ldots + w_m(x_{S_m})$. Тогда задача заключается в поиске присваивания, при котором суммарный вес ограничений максимальный.

Но мы рассмотрим более узкий класс задач $MAX\text{-}CSP$, а именно, мы ограничим максимальный размер области определения числом $k = 2$. Также ограничим количество всевозможных значений для каждой переменной числом $d$ и максимальный вес числом $R$.

**Определение.** Для задачи $MAX\text{-}k\text{-}SAT$ на вход подаётся $n$ переменных, число $d$, $m$ ограничений с весами из $\\{0, 1, \ldots, R\\}$, каждое из которых зависит не более, чем от $k$ переменных. На выход ожидается присваивание $x$ значений для $n$ переменных, при котором суммарный вес ограничений максимальный.

Обратите внимание, что невзвешенная версия, в которой каждое ограничение либо удовлетворяется, либо не удовлетворяется присвоением значений переменным, получается путем установки $R = 1$.

Важным частным случаем задачи $MAX\text{-}k\text{-}CSP$ является задача $MAX\text{-}k\text{-}SAT$, в которой каждая переменная является булевой и принимает одно из двух значений: _true_ или _false_, а каждое ограничение (дизъюнкт) представляет собой дизъюнкцию не более чем $k$ литералов и имеет вес $1$, если дизъюнкт выполняется (то есть принимает значение _true_), и $0$ в противном случае. Таким образом, любой алгоритм, решающий задачу $MAX\text{-}k\text{-}CSP$, тривиально решает и задачу $MAX\text{-}k\text{-}SAT$.

Ещё одной родственной задачей является задача $MAX\text{-}CUT$, которая получается как частный случай задачи $MAX\text{-}2\text{-}CSP$. Экземпляр задачи $MAX\text{-}CUT$ задаётся графом с $n$ вершинами (переменными) и $m$ рёбрами с весами. Требуется найти разбиение множества вершин, при котором суммарный вес рёбер, соединяющих вершины из разных частей разбиения, максимален.

## 3. Алгоритм для $MAX\text{-}2\text{-}CSP$

Зафиксируем экземпляр задачи $MAX\text{-}2\text{-}CSP$ с обозначениями, введёнными в предыдущем разделе. Пусть $M = mR$ — максимальный возможный суммарный вес. Для $r = 0, 1, \ldots, M$ обозначим через $\alpha_r$ число присваиваний переменных, при которых суммарный вес равен $r$. Нас интересует нахождение наибольшего $r$, для которого $\alpha_r > 0$.

Далее мы опишем алгоритм, который находит значения $\alpha_r$ для всех $r = 0, 1, \ldots, M$.
Для этого мы построим _произведение сумм_ следующим образом.
Пусть $\beta = 2^{l}$, где $l$ — целое число, удовлетворяющее неравенству
$d^{n} < 2^{l} \le 2 d^{n}$; величина $\beta$ будет использоваться в качестве основания
некоторых экспоненциальных выражений, как будет описано ниже.
Для каждого ограничения $c = 1, \ldots, m$ определим

$$
f_c(x_{S_c}) := \beta^{w_c(x_{S_c})} \in \\{1, \beta, \beta^2, \ldots, \beta^R\\}.
$$

Для любого присваивания $x \in \mathcal{X}$ рассмотрим произведение

$$
\prod_{c=1}^{m} f_c(x_{S_c});
$$

оно равно $\beta^{r}$, где $r$ — суммарный вес ограничений, выполняющихся при присваивании $x$.
Обозначим

$$
\gamma := \sum_{x \in \mathcal{X}} \prod_{c=1}^{m} f_c(x_{S_c}).
\tag{1}
$$

Нетрудно увидеть следующее:

**Лемма 1.**
Имеет место равенство

$$
\gamma = \alpha_0 + \alpha_1 \beta + \alpha_2 \beta^2 + \cdots + \alpha_M \beta^M.
$$

> **Доказательство.** Для каждого $r$ слагаемое $\beta^{r}$ появляется в сумме $(1)$ ровно $\alpha_r$ раз.

Кроме того, коэффициенты $\alpha_r$ могут быть легко восстановлены по значению $\gamma$.

**Лемма 2.** Дана $\gamma$, значения $\alpha_0, \alpha_1, \ldots, \alpha_M$ уникальны и могут быть найдены за время, линейное относительно $M \log{\beta}$.

> **Доказательство.** Каждый коэффициент $\alpha_r$ меньше, чем $\beta = 2^l$ (т.к. всего присваиваний может быть $\alpha_r \leq d^n < 2^l = \beta$). Значит в двоичном представлении каждые $\log{\beta}$ бит числа $\gamma$ содержат значения коэффициентов $\alpha_r$. Всего таких _вёдер_ для коэффициентов $M$ штук, поэтому по памяти хранение $\gamma$ занимает $O(M \log{\beta})$. Столько же требуется время, чтобы определить каждый коэффициент.

Теперь рассмотрим конкретно случай $k = 2$, где каждое ограничение зависит максимум от двух переменных.

**Теорема.** Найти оптимальный вес $W$ (т.е. решить задачу $COUNT\text{-}2\text{-}CSP$) можно за время $O(\mu(n M \log{d})d^{a + n'\omega})$, где $\mu(b) = b \log{b} \log{\log{b}}$, $n' = \lfloor n / 3\rfloor$ и $a = n - 3n' \in \\{0, 1, 2\\}$.

**Доказательство.** Для доказательства необходимо, чтобы каждая переменная принимала максимум $d$ различных значений.
Используя вышеприведённые леммы, покажем, что число $\gamma$ может быть посчитано за время $O(\mu(n M \log{d})d^{a + n'\omega})$. После мы сможем легко получить $r$, для которого $\alpha_r > 0$ (максимальный суммарный вес) и само число $\alpha_r$ (количество таких присваиваний).

Для начала предположим, что $n$ делится на $3$ без остатка. Пусть $\\{I, K, J\\}$ будет каким-то разбиением $\\{1, \ldots, n\\}$ на три непересекающихся подмножества размера $n / 3$. Построим разбиение $\\{A, B, C\\}$ множества индексов ограничений $\\{1, \ldots, m\\}$ следующим образом

$$
A := \\{c : S_c \subseteq I \cup J\\}, \\
B := \\{c : S_c \cap K \neq \emptyset \text{ и } S_c \cap J = \emptyset\\}, \\
C := \\{c : S_c \cap K \neq \emptyset \text{ и } S_c \cap J \neq \emptyset\\},
$$

Получили разбиения неперсекающихся множеств, т.к. области определения $S_c$ могут содержать максимум два элемента и не могу пересекать все три множества $I$, $J$ и $K$.

Продолжим, факторизуя произведение, возникающее в суммирующе-перемножающем
выражении~(1) для $\gamma$. Для всех присваиваний переменных $x \in \chi$
положим

$$
\mathcal{A}(x_I, x_J) := \prod_{c \in A} f_c(x_{S_c}), \\
\mathcal{B}(x_I, x_K) := \prod_{c \in B} f_c(x_{S_c}), \\
\mathcal{C}(x_J, x_K) := \prod_{c \in C} f_c(x_{S_c}).
$$

Заметим, что $x_I$, $x_J$ и $x_K$ образуют разбиение множества из $n$ переменных.
Ключевое наблюдение состоит в том, что

$$
\gamma
= \sum_{x_I} \sum_{x_J} \sum_{x_K}
\mathcal{A}(x_I, x_J)\, \mathcal{B}(x_I, x_K)\, \mathcal{C}(x_J, x_K) = \\
= \sum_{x_I} \sum_{x_J} \mathcal{A}(x_I, x_J)\, \mathcal{D}(x_I, x_J),
$$

где

$$
\mathcal{D}(x_I, x_J) := \sum_{x_K} \mathcal{B}(x_I, x_K)\, \mathcal{C}(x_J, x_K).
$$

Проанализируем время, необходимое для вычисления приведённых выше выражений.
Будем рассматривать $\mathcal{A}$ (аналогично $\mathcal{B}$ и $\mathcal{C}$) как матрицу размера
$d^{n/3} \times d^{n/3}$, где индексы строк и столбцов определяются биекциями
из $\mathcal{X}_I$ и $\mathcal{X}_J$ в множество $\{1, 2, \ldots, d^{n/3}\}$;
построение такого матричного представления влечёт лишь пренебрежимо малые
вычислительные затраты.

В этой интерпретации видно, что матрица $\mathcal{D}$ получается как произведение матрицы $\mathcal{B}$ и транспонированной матрицы $\mathcal{C}$. Следовательно, $\mathcal{D}$ может быть вычислена за $O(d^{n\omega/3})$ арифметических операций над числами, которые представимы в $O(nM \log d)$ битах (поскольку $\log \gamma < (M + 2)\log \beta \le (M + 2)\log(2 d^n)$). Известно, что два $b$-битных целых числа можно перемножить за $O(\mu(b))$ времени, где $\mu(b) = b \log b \log \log b$, а операции сложения и вычитания выполняются быстрее.
Следовательно, матрица $\mathcal{D}$ может быть вычислена за $O\bigl(\mu(nM \log d)\, d^{n\omega/3}\bigr)$ времени.

Наконец, отметим, что вычисление $\gamma$ по известной матрице $\mathcal{D}$ значительно
проще, поскольку в нём участвуют лишь две трети от $n$ переменных.

Теперь предположим, что $n$ не делится на $3$. Выберем
$a = n - 3\lfloor n/3 \rfloor < 3$ переменных и построим $d^a$ новых экземпляров
задачи для оставшихся $n - a$ переменных. Число $n - a$ делится на $3$, и по
описанной выше процедуре каждый экземпляр может быть решён за $O\bigl(\mu(nM \log d \, d^{(n-a)\omega/3}\bigr)$ времени, что даёт заявленную общую вычислительную сложность.

**Теорема.** Задача $MAX-2-CSP$ может быть решена за время $O(\mu(nM)d^{n\omega / 3})$, где $M = mR$ и $\mu(b) = b \log{b} \log{\log{b}}$.

**Доказательство.** Покажем, как найти оптимальное присваивание. Пусть $W$ — максимальный суммарный вес, который может быть получен некоторым присваиванием переменных. Как было показано выше, это значение можно вычислить за время $O(\mu(nM)d^{n\omega/3})$.

Теперь мы построим оптимальное присваивание, последовательно решая серию задач меньшего размера:

1. Для $i = 1, \ldots, n$:
   1. положим $x_i := 0$;
   1. заменим каждое ограничение $w_c$, область определения $S_c$ которого содержит $i$, на новое ограничение $w'_c$, определённое как $w'_c(x_{S_c \setminus \{i\}}) := w_c(x_{S_c});$
   1. вычислим оптимальный вес $W'$ для нового экземпляра задачи;
   1. если $W' < W$, положим $x_i := 1$.
1. Вернём присваивание $x$.

Данный алгоритм возвращает оптимальное присваивание, поскольку для каждого $i$ существует присваивание переменных $x_1, \ldots, x_{i-1}$ такое, что построенный на этом шаге новый экземпляр задачи имеет оптимальный вес $W$.

На $i$-й итерации описанного алгоритма решается экземпляр задачи с $n - i$ переменными за время $O(\mu(nM)d^{(n-i)\omega/3})$. Так как
$\sum_{i=0}^{n} d^{(n-i)\omega/3} < d^{n\omega/3} / (1 - d^{-\omega/3})$, общая временная сложность равна заявленной $O(\mu(nM d^{n\omega/3})$.

**Следствие.** Задачи $MAX-2-SAT$ могут быть решены за время $O(n m \log{n} \log{\log{n} 1.729^n})$.

**Доказательство.** Используем теорему выше с $d = 2$, $m \leq 4n^4$, $R = 1$ и $\omega < 2.372$.
