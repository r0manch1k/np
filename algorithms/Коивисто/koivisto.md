## 1. Введение

Покажем, что для данного набора $m$ ограничений над $n$ переменными, присваивание значений переменным, которое удовлетворяет максимальное количество ограничений ($MAX\text{-}2\text{-}CSP$) может быть найдено за время $O^{\*}(n m d^{n \omega / 3})$, где $d$ - максимальное число возможных значений для каждой переменной и $w < 2.372$ - экспонента произведения матриц над кольцом. Нотация $O^{\*}$ поглощает факторы, полилогарифмические от $m$ и $n$. Как следствие, задача $MAX\text{-}2\text{-}SAT$ и $MAX\text{-}CUT$ может быть решена за время $O^*(n m 1.729^n)$. Это улучшает предыдущий результат [Райна Виллиамса](./../Виллиамс/williams.md), сокращая полиномиальный фактор с $nm^3$ до $nm$.

## 2. Задача выполнения ограничений

Рассмотрим следующий вариант задачи определения максимального количества выполняющихся ограничений. Вход состоит из $n$ переменных $x_1, \ldots, x_n$, где каждая $x_i$ берёт свои значения из конечного множества $\chi_i$ размера $d_i$, и $m$ (взвешенных) ограничений $w_1, \ldots, w_m$, каждое из которых является целочисленной функцией над подмножеством переменных. Задача состоит в нахождении присваивания значений для переменных, при котором сумма весов выполненных ограничений будет максимальной.

Для удобства введём следующие обозначения.

_Областью определения_ $c$-ого ограничения $w_c$ назовём подмножество индексов $S_c \subseteq \\{1, \ldots, n\\}$, от которого будет зависеть вектор переменных $x_{s_c}$ со значениями из $\chi_{S_c}$ (_я так понимаю он это ввёл, чтобы устранить некоторую неопределённость c_ $a_v$ _у Виллиамса_). Здесь и далее используется индексирование через подмножества: если $S = \\{i_1, \ldots, i_k\\}$ с $1 \leq i_1 < \ldots < i_k \leq n$, то $\chi_S$ является $\chi_{i_1} \times \cdots \times \chi_{i_k}$, а $x_S$ будет $(x_{i_1}, \ldots, x_{i_k})$; для $S = \\{1, \ldots, n\\}$ индексы можем опустить.

Таким образом, ограничение $w_c$ отображает каждое частичное присваивание $x_{S_c}$ из $\chi_{S_c}$ в целое положительное число из $\\{0, 1, 2, \ldots\\}$ (не рассматриваем отрицательные веса). Будем говорить, что присваивание $x \in \chi$ удовлетворяет ограничению $w_c$, если значение $w_c(x_{S_c})$ больше нуля. _Суммарный вес_ ограничейний $w_1, \ldots, w_m$ при $x$ является суммой всех их весов - $w_1({x_{S_1}}) + \ldots + w_m(x_{S_m})$. Тогда задача заключается в поиске присваивания, при котором суммарный вес ограничений максимальный.

Но мы рассмотрим более узкий класс задач $MAX\text{-}CSP$, а именно, мы ограничим максимальный размер области определения числом $k = 2$. Также ограничим количество всевозможных значений для каждой переменной числом $d$ и максимальный вес числом $R$.

**Определение.** Для задачи $MAX\text{-}k\text{-}SAT$ на вход подаётся $n$ переменных, число $d$, $m$ ограничений с весами из $\\{0, 1, \ldots, R\\}$, каждое из которых зависит не более, чем от $k$ переменных. На выход ожидается присваивание $x$ значений для $n$ переменных, при котором суммарный вес ограничений максимальный.

Обратите внимание, что невзвешенная версия, в которой каждое ограничение либо удовлетворяется, либо не удовлетворяется присвоением значений переменным, получается путем установки $R = 1$.

Важным частным случаем задачи $MAX\text{-}k\text{-}CSP$ является задача $MAX\text{-}k\text{-}SAT$, в которой каждая переменная является булевой и принимает одно из двух значений: _true_ или _false_, а каждое ограничение (дизъюнкт) представляет собой дизъюнкцию не более чем $k$ литералов и имеет вес $1$, если дизъюнкт выполняется (то есть принимает значение _true_), и $0$ в противном случае. Таким образом, любой алгоритм, решающий задачу $MAX\text{-}k\text{-}CSP$, тривиально решает и задачу $MAX\text{-}k\text{-}SAT$.

Ещё одной родственной задачей является задача $MAX\text{-}CUT$, которая получается как частный случай задачи $MAX\text{-}2\text{-}CSP$. Экземпляр задачи $MAX\text{-}CUT$ задаётся графом с $n$ вершинами (переменными) и $m$ рёбрами с весами. Требуется найти разбиение множества вершин, при котором суммарный вес рёбер, соединяющих вершины из разных частей разбиения, максимален.

## 3. Алгоритм для $MAX\text{-}2\text{-}CSP$

Зафиксируем экземпляр задачи $MAX\text{-}2\text{-}CSP$ с обозначениями, введёнными в предыдущем разделе. Пусть $M = mR$ — максимальный возможный суммарный вес. Для $r = 0, 1, \ldots, M$ обозначим через $\alpha_r$ число присваиваний переменных, при которых суммарный вес равен $r$. Нас интересует нахождение наибольшего $r$, для которого $\alpha_r > 0$.

Далее мы опишем алгоритм, который находит значения $\alpha_r$ для всех $r = 0, 1, \ldots, M$.
Для этого мы построим _произведение сумм_ следующим образом.
Пусть $\beta = 2^{l}$, где $l$ — целое число, удовлетворяющее неравенству
$d^{n} < 2^{l} \le 2 d^{n}$; величина $\beta$ будет использоваться в качестве основания
некоторых экспоненциальных выражений, как будет описано ниже.
Для каждого ограничения $c = 1, \ldots, m$ определим

$$
f_c(x_{S_c}) := \beta^{w_c(x_{S_c})} \in \\{1, \beta, \beta^2, \ldots, \beta^R\\}.
$$

Для любого присваивания $x \in \mathcal{X}$ рассмотрим произведение

$$
\prod_{c=1}^{m} f_c(x_{S_c});
$$

оно равно $\beta^{r}$, где $r$ — суммарный вес ограничений, выполняющихся при присваивании $x$.
Обозначим

$$
(1) \quad \gamma := \sum_{x \in \mathcal{X}} \prod_{c=1}^{m} f_c(x_{S_c}).
$$

Нетрудно увидеть следующее:

**Лемма 1.**
Имеет место равенство

$$
\gamma = \alpha_0 + \alpha_1 \beta + \alpha_2 \beta^2 + \cdots + \alpha_M \beta^M.
$$

> **Доказательство.** Для каждого $r$ слагаемое $\beta^{r}$ появляется в сумме $(1)$ ровно $\alpha_r$ раз.

Кроме того, коэффициенты $\alpha_r$ могут быть легко восстановлены по значению $\gamma$.

**Лемма 2.** Дана $\gamma$, значения $\alpha_0, \alpha_1, \ldots, \alpha_M$ уникальны и могут быть найдены за время, линейное относительно $M \log{\beta}$.

> **Доказательство.** Каждый коэффициент $\alpha_r$ меньше, чем $\beta = 2^l$ (т.к. всего присваиваний может быть $\alpha_r \leq d^n < 2^l = \beta$). Значит в двоичном представлении каждые $\log{\beta}$ бит числа $\gamma$ содержат значения коэффициентов $\alpha_r$. Всего таких _вёдер_ для коэффициентов $M$ штук, поэтому по памяти хранение $\gamma$ занимает $O(M \log{\beta})$. Столько же требуется время, чтобы определить каждый коэффициент.

Теперь рассмотрим конкретно случай $k = 2$, где каждое ограничение зависит максимум от двух переменных.

**Теорема.** Найти оптимальный вес $W$ (т.е. решить задачу $COUNT\text{-}2\text{-}CSP$) можно за время $O(\mu(n M \log{d})d^{a + n'\omega})$, где $\mu(b) = b \log{b} \log{\log{b}}$, $n' = \lfloor n / 3\rfloor$ и $a = n - 3n' \in \\{0, 1, 2\\}$.

**Доказательство.** Для доказательства необходимо, чтобы каждая переменная принимала максимум $d$ различных значений.
Используя вышеприведённые леммы, покажем, что число $\gamma$ может быть посчитано за время $O(\mu(n M \log{d})d^{a + n'\omega})$. После мы сможем легко получить $r$, для которого $\alpha_r > 0$ (максимальный суммарный вес) и само число $\alpha_r$ (количество таких присваиваний).

Для начала предположим, что $n$ делится на $3$ без остатка. Пусть $\\{I, K, J\\}$ будет каким-то разбиением $\\{1, \ldots, n\\}$ на три непересекающихся подмножества размера $n / 3$. Построим разбиение $\\{A, B, C\\}$ множества индексов ограничений $\\{1, \ldots, m\\}$ следующим образом

$$
A := \\{c : S_c \subseteq I \cup J\\}, \\
B := \\{c : S_c \cap K \neq \emptyset \text{ и } S_c \cap J = \emptyset\\}, \\
C := \\{c : S_c \cap K \neq \emptyset \text{ и } S_c \cap J \neq \emptyset\\},
$$

Получили разбиения неперсекающихся множеств, т.к. области определения $S_c$ могут содержать максимум два элемента и не могу пересекать все три множества $I$, $J$ и $K$.

Продолжим, факторизуя произведение, возникающее в суммирующе-перемножающем
выражении~(1) для $\gamma$. Для всех присваиваний переменных $x \in \chi$
положим

$$
\mathcal{A}(x_I, x_J) := \prod_{c \in A} f_c(x_{S_c}), \\
\mathcal{B}(x_I, x_K) := \prod_{c \in B} f_c(x_{S_c}), \\
\mathcal{C}(x_J, x_K) := \prod_{c \in C} f_c(x_{S_c}).
$$

Заметим, что $x_I$, $x_J$ и $x_K$ образуют разбиение множества из $n$ переменных.
Ключевое наблюдение состоит в том, что

$$
\gamma
= \sum_{x_I} \sum_{x_J} \sum_{x_K}
\mathcal{A}(x_I, x_J)\, \mathcal{B}(x_I, x_K)\, \mathcal{C}(x_J, x_K) = \\
= \sum_{x_I} \sum_{x_J} \mathcal{A}(x_I, x_J)\, \mathcal{D}(x_I, x_J),
$$

где

$$
\mathcal{D}(x_I, x_J) := \sum_{x_K} \mathcal{B}(x_I, x_K)\, \mathcal{C}(x_J, x_K).
$$

Проанализируем время, необходимое для вычисления приведённых выше выражений.
Будем рассматривать $\mathcal{A}$ (аналогично $\mathcal{B}$ и $\mathcal{C}$) как матрицу размера
$d^{n/3} \times d^{n/3}$, где индексы строк и столбцов определяются биекциями
из $\mathcal{X}_I$ и $\mathcal{X}_J$ в множество $\\{1, 2, \ldots, d^{n/3}\\}$;
построение такого матричного представления влечёт лишь пренебрежимо малые
вычислительные затраты.

В этой интерпретации видно, что матрица $\mathcal{D}$ получается как произведение матрицы $\mathcal{B}$ и транспонированной матрицы $\mathcal{C}$. Следовательно, $\mathcal{D}$ может быть вычислена за $O(d^{n\omega/3})$ арифметических операций над числами, которые представимы в $O(nM \log d)$ битах (поскольку $\log \gamma < (M + 2) \log \beta \le (M + 2) \log 2 d^{n}$). Известно, что два $b$-битных целых числа можно перемножить за $O(\mu(b))$ времени, где $\mu(b) = b \log b \log \log b$, а операции сложения и вычитания выполняются быстрее.
Следовательно, матрица $\mathcal{D}$ может быть вычислена за $O\bigl(\mu(nM \log d)\, d^{n\omega/3}\bigr)$ времени.

Наконец, отметим, что вычисление $\gamma$ по известной матрице $\mathcal{D}$ значительно
проще, поскольку в нём участвуют лишь две трети от $n$ переменных.

Теперь предположим, что $n$ не делится на $3$. Выберем
$a = n - 3\lfloor n/3 \rfloor < 3$ переменных и построим $d^a$ новых экземпляров
задачи для оставшихся $n - a$ переменных. Число $n - a$ делится на $3$, и по
описанной выше процедуре каждый экземпляр может быть решён за $O\bigl(\mu(nM \log d \, d^{(n-a)\omega/3}\bigr)$ времени, что даёт заявленную общую вычислительную сложность.

**Теорема.** Задача $MAX-2-CSP$ может быть решена за время $O(\mu(nM)d^{n\omega / 3})$, где $M = mR$ и $\mu(b) = b \log{b} \log{\log{b}}$.

**Доказательство.** Покажем, как найти оптимальное присваивание. Пусть $W$ — максимальный суммарный вес, который может быть получен некоторым присваиванием переменных. Как было показано выше, это значение можно вычислить за время $O(\mu(nM)d^{n\omega/3})$.

Теперь мы построим оптимальное присваивание, последовательно решая серию задач меньшего размера:

1. Для $i = 1, \ldots, n$:
   1. положим $x_i := 0$;
   1. заменим каждое ограничение $w_c$, область определения $S_c$ которого содержит $i$, на новое ограничение $w^i_c$, определённое как $w^i_c(x_{S_c \ \\{i\\}}) := w_c(x_{S_c})$;
   1. вычислим оптимальный вес $W_i$ для нового экземпляра задачи;
   1. если $W_i < W$, положим $x_i := 1$.
1. Вернём присваивание $x$.

Данный алгоритм возвращает оптимальное присваивание, поскольку для каждого $i$ существует присваивание переменных $x_1, \ldots, x_{i-1}$ такое, что построенный на этом шаге новый экземпляр задачи имеет оптимальный вес $W$.

На $i$-й итерации описанного алгоритма решается экземпляр задачи с $n - i$ переменными за время $O(\mu(nM)d^{(n-i)\omega/3})$. Так как
$\sum_{i=0}^{n} d^{(n-i)\omega/3} < d^{n\omega/3} / (1 - d^{-\omega/3})$, общая временная сложность равна заявленной $O(\mu(nM d^{n\omega/3})$.

**Следствие.** Задачи $MAX-2-SAT$ могут быть решены за время $O(n m \log{n} \log{\log{n} 1.729^n})$.

**Доказательство.** Используем теорему выше с $d = 2$, $m \leq 4n^4$, $R = 1$ и $\omega < 2.372$.

## 4. Реализация алгоритма Коивисто для $MAX\text{-}CUT$

Теперь на основе алгоритма Коивисто решим задачу $MAX\text{-}CUT$ на языке Go.

В отличие от алгоритма Виллиамса, здесь используется алгебраическое представление задачи и ускорение перебора с помощью умножения матриц над большими числами, кодирующими количество выполненных ограничений.

### Задача

Входные данные содержат: число $n$ — количество вершин графа $G = (V, E)$. Далее на отдельных строках перечисляются пары вершин, соединённых рёбрами.

Требуется найти такое разбиение множества вершин на два подмножества, при котором число рёбер, имеющих концы в разных подмножествах, максимально. В качестве ответа необходимо вывести множество вершин, содержащее первую вершину.

### Общая идея алгоритма

Алгоритм Коивисто основан на следующей идее:

1. Вершины, для которых неизвестны раскраски, разбиваем на три непересекающихся множества $I$, $J$ и $K$;
1. Формируем матрицы с весами (количеством переходных рёбер) между этими множествами вершин с разными их раскрасками. При чём количество переходных рёбер при различных раскрасках кодируется в степенях некоторого числа $\beta$;
1. Суммарный вклад всех раскрасок вычисляется через:
   $\sum_{x_I, x_J, x_K} \beta^{w(x_I, x_J, x_K)}$
   где $w$ — число выполненных ограничений при данной раскраске;
1. Для быстрого вычисления $\gamma$ используется следующее матричное выражение: $\langle A, B \times C^\top \rangle$

Максимальная степень $\beta$, имеющая ненулевой коэффициент, соответствует оптимальному разрезу.

### Представление графа

Граф $G$ хранится в виде матрицы смежности.

```go
var n int
var m int
var G [][]bool
```

Если $n < 3$, то оптимальный разрез тривиален.

```go
if n < 3 {
   fmt.Println("1")
   return
}
```

### Функция нахождения максимального разреза

В функции `maxcut` происходит инициализация значений $l$ (число, равное количеству бит, достаточного для кодирования переходных ребёр) и $M$ (максимальное количество рёбер, которые могут быть переходными).

```go
l = n + 1
M = m * R
```

Инициализируем начальную раскраску для вершин, а именно - все вершины не раскрашены. Для этого присваем им значение $-1$.

```go
coloring := make([]int8, n)
for i := range n {
   coloring[i] = -1
}
```

Далее функцией `countcut` вычисляется максимальное количество переходных рёбер $W$ в данном графе $G$.

```go
W, _ := countcut(coloring)
```

Непосредственно само разбиение находится, как было описано в статье, через присваивание каждой переменной какого-то значения и пересчётом $W_i$ при данной раскраске.

```go
for i := range n {
   coloring[i] = 0
   Wi, _ := countcut(coloring)
   if Wi < W {
      coloring[i] = 1
   }
}
```

### Функция веса

Далее будет использоваться функция веса $w$, которая вычисляет количество переходных рёбер между двумя подмножествами вершин $I$ и $J$ при заданных раскрасках.

```go
func w(xI uint64, xJ uint64, I []int, J []int) int
```

Если $I = J$, то результат делится пополам, так как каждое ребро из-за особенностей реализации учитывается дважды.

### Функция подсчета максимального количества переходных ребёр

Рассмотрим метод `countcut`.

Он начинается с формирования множеств с номерами покрашенных и непокрашенных вершин в переданной раскраске

```go
uncolored := make([]int, 0, n)

colored := make([]int, 0, n)

for i, u := range coloring {
   if u < 0 {
      uncolored = append(uncolored, i)
   } else {
      colored = append(colored, i)
   }
}
```

Вычисляем нужные нам размерности

```go
N := len(uncolored)

// Размер каждого разбиения нераскрашенных вершин графа
var p int = N / 3
```

Далее, следуя алгоритму из статьи, формируем множества $I$, $J$ и $K$ из нераскрашенных вершин

```go
// Разбиения нераскрашенных вершин графа
I, J, K := make([]int, p), make([]int, p), make([]int, p)

// Тривиальное распределение вершин для получения непересекающихся множеств
for i := range p {
   I[i] = uncolored[i]
   J[i] = uncolored[p+i]
   K[i] = uncolored[2*p+i]
}
```

Но так как количество нераскрашенных вершин может быть не кратно трём, то будут оставаться нераскрашенные вершины, невошедшие в множества $I$, $J$ и $K$.

Их будет $a$ штук и их мы обрабатываем отдельно. А именно, мы будем перебирать для них $2^a$ раскрасок и добавлять к множеству $K$ вместе уже с раскрашенными вершинами в `coloring`

```go
var a int = N - 3*p

// Все вершины, для которых уже известны раскраски
rest := make([]int, 0, len(colored)+a)

// Кладём туда невошедшие в разбиения вершины, потому что бы потом будем перебирать для них раскраски
for i := range a {
   rest = append(rest, uncolored[3*p+i])
}

// ...и уже раскрашенные вершины
rest = append(rest, colored...)

// Для возможности подсчёта и удобства прикрепляем уже раскрашенные вершины к множеству K
K = append(K, rest...)
```

Определяем вспомогательные переменные

```go
// Размер матриц
q := 1 << p

// Вспомогательная переменная для хранения суммарного веса выполненных ограничений при
// конкретных присваиваниях (в нашем случае, переходных рёбер при конкретных раскрасках)
var r int

// Вспомогательная переменная для хранения \beta^r
var betar *big.Int
```

Далее мы будем в цикле перебирать раскраски для оставшихся $a$ вершин, которые, напомню, лежат в $K$. Значит элементы матриц, зависящие от множества $K$, тоже будут пересчитываться. Но по статье от множества $K$ не зависит матрица $\mathcal{A}$, поэтому заполняем её сразу

```go
// Матрицу A заполним сразу, т.к. она не зависит от элементов из K
A := make([][]*big.Int, q)
for xI := range uint64(q) {
   A[xI] = make([]*big.Int, q)
   for xJ := range uint64(q) {
      r = w(xI, xI, I, I) + w(xI, xJ, I, J) + w(xJ, xJ, J, J)
      betar = new(big.Int)
      betar.SetBit(betar, l*r, 1)
      A[xI][xJ] = betar
   }
}
```

Делаем битовую маску раскраски для уже раскрашенных в `coloring` вершин, которая пригодится нам далее

```go
// Непосредственно переданная в функцию раскраска
var xcolored uint64

for i, u := range colored {
   xcolored |= uint64(coloring[u]) << i
}
```

Ещё инициализируем вспомогательные переменные

```go
// Раскраска для уже раскрашенных вершин + невошедших в разбиения
var xrest uint64

// Максимальное количество переходных рёбер при переданной в функцию раскраске
var W int

// Сколько раз достигается W
var alphaW uint64
```

Теперь начинаем как раз-таки пееребирать раскраски тех $a$ вершин и сразу раскраску для всех присоединённых к $K$ вершин.

```go
// Перебираем все раскаски невошедших в разбиения вершин
for xa := range 1 << a {
   xrest = (xcolored << a) | uint64(xa)
```

Если у нас количество нераскрашенных вершин на вход меньше трёх, то тогда множества $I$, $J$ будут пустыми, а в $K$ попадут все вершины. Поэтому нет смыысла строить матриц и их переменожать. Просто этот случай рассматриваем в цикле отдельно и считаем $W$ следующим образом

```go
   // Случай когда количество нераскрашенных вершин < 3
   //
   // Тогда множество K содержит все вершины графа и мы
   // счиатем для него количество переходных ребёр
   if p < 1 {
      r = w(xrest, xrest, K, K)
      if r > W {
         W = r
         alphaW = 1
      } else if r == W {
         alphaW += 1
      }
      continue
   }
```

В остальных случая заполняем матрицы как опписано в статье и считаем число $\gamma$

```go
   for xI := range uint64(q) {
      for k := range uint64(q) {
         xK := (xrest << p) | k
         r = w(xI, xK, I, K) + w(xK, xK, K, K)
         betar = new(big.Int)
         betar.SetBit(betar, l*r, 1)
         B[xI][k] = betar
      }
   }

   for xJ := range uint64(q) {
      for k := range uint64(q) {
         xK := (xrest << p) | k
         r = w(xJ, xK, J, K)
         betar = new(big.Int)
         betar.SetBit(betar, l*r, 1)
         C[xJ][k] = betar
      }
   }

   D := matmul(B, C, true)

   // Считаем именно сумму произведений соответствующих элементов
   gamma := matscalar(A, D)
```

Находим максимальное количество переходных рёбер при данных раскрасках

```go
   for r := M; r >= 0; r-- {
      alpha := extractbits(gamma, r, l)
      if alpha == 0 {
         continue
      }
      if r > W {
         W = r
         alphaW = alpha
         break
      }
      if r == W {
         alphaW += 1
         break
      }
   }
```

После этого цикла возвращаем результат

```go
return W, alphaW
```

### Алгебраическое ускорение

Вычисляется матрица:

$$
D = B \times C^\top
$$

Затем считается скалярное произведение:

$$
\gamma = \langle A, D \rangle
$$

```go
D := matmul(B, C, true)
gamma := matscalar(A, D)
```

Каждый бит в числе gamma соответствует количеству раскрасок, дающих фиксированное число переходных рёбер.

### Извлечение ответа

Максимальное $r$, для которого коэффициент при $\beta^r$ ненулевой, является оптимальным значением $MAX\text{-}CUT$.

```go
alpha := extractbits(gamma, r, l)
```

Также подсчитывается количество достижений этого максимума.

### Полный алгоритм

Полная реализация алгоритма Коивисто приведена ниже:

```go
// Гаечка. Задача о максимальном разрезе в графе. Алгоритм Коивисто

package main

import (
	"fmt"
	"math/big"
)

// n - количество вершин
var n int

// m - количество ребёр
var m int

// G - исходный граф
var G [][]bool

// Максимальный вес ограничения (в нашем случае, ребро либо переходое, либо нет)
var R int = 1

// Максимальный суммарный вес ограничений (в нашем случае, сколько рёбер может быть переходными)
var M int

// Количество бит, достаточное для кодирования количества выполненных ограничений (в нашем случае, переходных ребёр)
var l int

// Возвращает количество переходных ребёр между вершинами I и J
// при их раскрасках xI и xJ соответственно
func w(xI uint64, xJ uint64, I []int, J []int) int {
	var transitions int

	// Если множества вершин I и J равны, то необходимо поделить
	// результат пополам из-за специфики реализации
	var ii bool

	for i, u := range I {
		for j, v := range J {
			if !ii && (u == v) {
				ii = true
			}
			if G[u][v] && ((1<<i)&xI > 0) != ((1<<j)&xJ > 0) {
				transitions += 1
			}
		}
	}

	if ii && transitions > 0 {
		transitions /= 2
	}

	return transitions
}

// Умножает две матрицы с элементами *big.Int
//
// Если параметр T=true, то вычисляется A x B^T
func matmul(A, B [][]*big.Int, T bool) [][]*big.Int {
	N := len(A)

	D := make([][]*big.Int, N)
	for i := 0; i < N; i++ {
		D[i] = make([]*big.Int, N)
		for j := 0; j < N; j++ {
			D[i][j] = new(big.Int)
		}
	}

	tmp := new(big.Int)

	for i := 0; i < N; i++ {
		for k := 0; k < N; k++ {
			aik := A[i][k]
			if aik.Sign() == 0 {
				continue
			}

			for j := 0; j < N; j++ {
				var bkj *big.Int
				if T {
					bkj = B[j][k]
				} else {
					bkj = B[k][j]
				}

				if bkj.Sign() == 0 {
					continue
				}

				tmp.Mul(aik, bkj)
				D[i][j].Add(D[i][j], tmp)
			}
		}
	}

	return D
}

// Вычисляет скалярное произведение матриц с элементами *big.Int
//
// \sum_{i=1}^n \sum_{j=1}^n a_{ij} b_{ij}
func matscalar(A, B [][]*big.Int) *big.Int {
	N := len(A)
	sum := big.NewInt(0)
	tmp := new(big.Int)

	for i := 0; i < N; i++ {
		for j := 0; j < N; j++ {
			if A[i][j].Sign() == 0 || B[i][j].Sign() == 0 {
				continue
			}
			tmp.Mul(A[i][j], B[i][j])
			sum.Add(sum, tmp)
		}
	}

	return sum
}

// Извлекает i-e size бит из числа
func extractbits(a *big.Int, i int, size int) uint64 {
	shifted := new(big.Int).Rsh(a, uint(i*size))
	return shifted.Uint64() & (uint64(1)<<size - 1)
}

// Находит максимальный разрез
//
// Возвращает раскраску вершин графа G
func maxcut() []int8 {
	l = n + 1
	M = m * R

	coloring := make([]int8, n)
	for i := range n {
		coloring[i] = -1
	}

	W, _ := countcut(coloring)

	for i := range n {
		coloring[i] = 0
		Wi, _ := countcut(coloring)
		if Wi < W {
			coloring[i] = 1
		}
	}

	return coloring
}

// Находит максимальное количество переходных ребёр и сколько раз оно достигается
//
// На вход подаётся частичная раскраска вершин графа G
func countcut(coloring []int8) (int, uint64) {
	// Получим списки раскрашенных и нераскрашенных вершин

	uncolored := make([]int, 0, n)

	colored := make([]int, 0, n)

	for i, u := range coloring {
		if u < 0 {
			uncolored = append(uncolored, i)
		} else {
			colored = append(colored, i)
		}
	}

	N := len(uncolored)

	// Размер каждого разбиения нераскрашенных вершин графа
	var p int = N / 3

	// Разбиения нераскрашенных вершин графа
	I, J, K := make([]int, p), make([]int, p), make([]int, p)

	// Тривиальное распределение вершин для получения непересекающихся множеств
	for i := range p {
		I[i] = uncolored[i]
		J[i] = uncolored[p+i]
		K[i] = uncolored[2*p+i]
	}

	// Количество невошедших в разбиения вершин
	var a int = N - 3*p

	// Все вершины, для которых уже известны раскраски
	rest := make([]int, 0, len(colored)+a)

	// Кладём туда невошедшие в разбиения вершины, потому что бы потом будем перебирать для них раскраски
	for i := range a {
		rest = append(rest, uncolored[3*p+i])
	}

	// ...и уже раскрашенные вершины
	rest = append(rest, colored...)

	// Непосредственно переданная в функцию раскраска
	var xcolored uint64

	for i, u := range colored {
		xcolored |= uint64(coloring[u]) << i
	}

	// Для возможности подсчёта и удобства прикрепляем уже раскрашенные вершины к множеству K
	K = append(K, rest...)

	// Размер матриц
	q := 1 << p

	// Вспомогательная переменная для хранения суммарного веса выполненных ограничений при
	// конкретных присваиваниях (в нашем случае, переходных рёбер при конкретных раскрасках)
	var r int

	// Вспомогательная переменная для хранения \beta^r
	var betar *big.Int

	// Матрицу A заполним сразу, т.к. она не зависит от элементов из K
	A := make([][]*big.Int, q)
	for xI := range uint64(q) {
		A[xI] = make([]*big.Int, q)
		for xJ := range uint64(q) {
			r = w(xI, xI, I, I) + w(xI, xJ, I, J) + w(xJ, xJ, J, J)
			betar = new(big.Int)
			betar.SetBit(betar, l*r, 1)
			A[xI][xJ] = betar
		}
	}

	// Остальные матрицы просто инициализируем

	B := make([][]*big.Int, q)
	for i := range uint64(q) {
		B[i] = make([]*big.Int, q)
	}

	C := make([][]*big.Int, q)
	for i := range uint64(q) {
		C[i] = make([]*big.Int, q)
	}

	// Раскраска для уже раскрашенных вершин + невошедших в разбиения
	var xrest uint64

	// Максимальное количество переходных рёбер при переданной в функцию раскраске
	var W int

	// Сколько раз достигается W
	var alphaW uint64

	// Перебираем все раскаски невошедших в разбиения вершин
	for xa := range 1 << a {
		xrest = (xcolored << a) | uint64(xa)

		// Случай когда количество нераскрашенных вершин < 3
		//
		// Тогда множество K содержит все вершины графа и мы
		// счиатем для него количество переходных ребёр
		if p < 1 {
			r = w(xrest, xrest, K, K)
			if r > W {
				W = r
				alphaW = 1
			} else if r == W {
				alphaW += 1
			}
			continue
		}

		for xI := range uint64(q) {
			for k := range uint64(q) {
				xK := (xrest << p) | k
				r = w(xI, xK, I, K) + w(xK, xK, K, K)
				betar = new(big.Int)
				betar.SetBit(betar, l*r, 1)
				B[xI][k] = betar
			}
		}

		for xJ := range uint64(q) {
			for k := range uint64(q) {
				xK := (xrest << p) | k
				r = w(xJ, xK, J, K)
				betar = new(big.Int)
				betar.SetBit(betar, l*r, 1)
				C[xJ][k] = betar
			}
		}

		D := matmul(B, C, true)

		// Считаем именно сумму произведений соответствующих элементов
		gamma := matscalar(A, D)

		for r := M; r >= 0; r-- {
			alpha := extractbits(gamma, r, l)
			if alpha == 0 {
				continue
			}
			if r > W {
				W = r
				alphaW = alpha
				break
			}
			if r == W {
				alphaW += 1
				break
			}
		}
	}

	return W, alphaW
}

func main() {
	fmt.Scan(&n)

	G = make([][]bool, n)
	for i := range n {
		G[i] = make([]bool, n)
	}

	// На вход по очереди подаются две вершины (ребра)
	var u, v int

	for {
		_, err := fmt.Scanln(&u, &v)
		// Пробел или EOF
		if err != nil {

		}
		G[u-1][v-1] = true
```
